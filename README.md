Projeto Multidisciplinar – Qualidade de Software
Tema
Planejamento e Garantia da Qualidade de Software para o Sistema de Gestão da Rede de Franquias Alimentícias Raízes do Nordeste.

Objetivo
Desenvolver uma estratégia de Garantia da Qualidade (QA) para um sistema de franquias alimentícias, contemplando requisitos funcionais, requisitos não funcionais, métricas, desempenho, segurança, conformidade com a LGPD e rastreabilidade.

Ferramentas Utilizadas
Postman
Apache JMeter
OWASP ZAP
Chrome DevTools
Draw.io
Evidências de Testes
CT01 – Consulta de Usuário (GET)
Ferramenta: Postman

CT02 – Cadastro de Pedido (POST)
Ferramenta: Postman

CT03 – Responsividade Mobile
Ferramenta: Chrome DevTools

CT04 – Teste de Desempenho
Ferramenta: Apache JMeter

CT05 – Teste de Segurança
Ferramenta: OWASP ZAP
